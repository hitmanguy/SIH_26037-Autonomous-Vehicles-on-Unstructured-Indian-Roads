# Epsilon · C3 detector v1 (YOLOv8s fine-tuned on IDD)

Camera object detector for PS26037, trained on the India Driving Dataset (IDD Detection, 31.5k images, 60 epochs).
**mAP50 0.503 · mAP50-95 0.321** (stock YOLOv8s on the same classes: mean AP50 0.197 → ours 0.487).
~64 ms/frame (~16 fps) in MATLAB on an RTX 4050 laptop GPU.

**Classes (12):** person, rider, car, bus, truck, autorickshaw, motorcycle, bicycle, animal, traffic sign, traffic light, vehicle fallback (tractors, carts, etc.)

## You need
| | |
|---|---|
| MATLAB | **R2025b, latest Update** (older Updates hit an `onnxmex` error) |

## Quick start
1. Unzip anywhere. Keep all files together; **don't rename `+best_matlab`**.
2. Open a fresh MATLAB, `cd` into this folder, run `check_setup`.
   Everything should say OK and annotated images appear in `check_output\`.
3. In your own code:
   ```matlab
   addpath('<path to C3_detector_v1>');
   det = load_c3_detector();
   [bboxes, scores, labels] = detect(det, I);   % bboxes = [x y w h] in pixels
   ```

## If something fails
- **`yolov8ObjectDetector` not found** but the add-on shows *Enabled*: restart MATLAB. Still missing → Add-On Manager → disable then enable the YOLO v8 add-on (`check_setup` tries this for you).
- Don't run `restoredefaultpath` to "clean up": it removes add-ons from the path for that session.
- **.mat won't load**: run `C3b_import_to_matlab.m`. It rebuilds the detector from `best_matlab.onnx` into `rebuild_output\` (the shipped .mat is left untouched).

| `test_images\` | 4 IDD frames for the test (side camera, billboard, village, rear) |
